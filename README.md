# iZombie

Roblox-Zombie-Spiel, synchronisiert mit [Rojo](https://rojo.space).

## Starten
1. `rojo serve` in diesem Ordner ausführen (oder über die Rojo-Erweiterung in VS Code).
2. In Roblox Studio: **Plug-ins → Rojo → Connect**.

## Struktur
- `src/server` → ServerScriptService
- `src/client` → StarterPlayerScripts
- `src/shared` → ReplicatedStorage
